# eidos

eidos (εἶδος — form, essence, type) is the proof assistant for [[cyber]]. CIC type theory over [[Goldilocks field]] elements; the type checker is a [[nox]] program — executing it produces a [[zheng]] STARK certificate. Every proved theorem becomes a [[cyberlink]] in the [[cybergraph]], closing the loop with [[zheng]]: zheng proves execution correct, eidos proves programs correct.
