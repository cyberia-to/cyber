# bita

Bit-by-bit Rust reimplementation of Bitcoin Core. Contains `rbtc-*` crates: consensus, hash5 (Hash5 PoW + qhash light-cone attack), node, wallet, storage (fjall), and crypto (k256). The QTC sampling-based qPoW hardfork proposal and implementation live here, bridging Bitcoin-family consensus with the [[cyber]] proof stack.
