# zoya

ProgPoWZ (ZANO) miner for Apple Silicon. Built on [[honeycrisp]] following the [[mona]] and [[erga]] patterns. Phase 1 (primitives + CPU reference) is complete; Phase 2 (Metal GPU wiring) is next, targeting the same unified-memory zero-copy dispatch strategy used across the [[cyber]] miner family.
