# nu

Local fork/vendor of Nushell used as the primary shell across the [[cyber]] dev environment. All interactive dev sessions run inside it; scripting conventions across [[cyber]], [[cyb]], and the miner family ([[mona]], [[erga]], [[xena]], [[zoya]]) are written in nu. Forks track upstream Nushell with [[cyber]]-specific patches.
