# game theory

the discipline that studies strategic interaction between agents. game theory provides the formal language for reasoning about [[equilibrium]], [[cooperation]], and [[mechanism design]]. it bridges [[game]] (the phenomenon of strategic choice), [[math]] (the formal tools), and [[socio]] (the institutional applications)

in the [[crystal]], game theory spans three domains:

- [[game]] — [[equilibrium]], [[cooperative games]], [[Shapley value]], [[public goods]], [[auction]], [[externality]]
- [[math]] — fixed point theorems, [[probability]], [[combinatorics]], [[optimization]]
- [[socio]] — voting theory, [[governance]], [[constitution]], institutional design

## branches

- non-cooperative game theory → [[game]] + [[math]] (Nash equilibrium, dominant strategies)
- cooperative game theory → [[game]] ([[cooperative games]], [[Shapley value]], coalitions)
- mechanism design → [[game]] + [[crypto]] ([[auction]], [[public goods]], incentive compatibility)
- evolutionary game theory → [[game]] + [[bio]] (evolutionary stable strategies, replicator dynamics)
- algorithmic game theory → [[game]] + [[comp]] (computational complexity of equilibria)
