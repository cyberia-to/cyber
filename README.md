## install

```bash
cargo install soft3
cargo install cyb
soft3 sync          # default network: space-pussy
```

space-pussy is a chaosnet — a live proving ground. everything on it is test: the tokens, the [[rewards]], the state. mainnet arrives at [[launch]].
