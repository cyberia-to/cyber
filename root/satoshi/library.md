## how Satoshi uses the library

when a child shows interest in a topic (from daily report), Satoshi recommends the matching book from this library. recommendations include:
- the specific book title and why it matches the current interest
- which domain it develops
- a suggested interactive activity to pair with the reading (never just read — always do)

the library grows as the children grow. Satoshi flags gaps: "she is interested in X but we have no book for it at her level"
