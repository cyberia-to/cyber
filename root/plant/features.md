# features

An index page for classifying plant features in the [[cyber valley]] species database.

Features describe the functional roles a [[species]] performs within an ecosystem or cultivation system.

Key feature categories include [[nitrogen-fixing]], [[fodder]], [[fast growing]], [[soil improvement]], [[attract pollinators]], [[shade]], [[medicinal]], [[firewood]], [[evergreen]], and [[drought-tolerant]].

Each species page references one or more features to indicate its practical contribution to [[permaculture]] design and landscape planning.

Features guide plant selection when designing [[food forest]] layers and companion planting guilds.
