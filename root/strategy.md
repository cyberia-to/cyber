# strategy

the canonical anchor for what we are doing and why.

## the triplet

```
purpose  →  make planets think
vision   →  type 1 civilization
mission  →  build cyberia, led by superintelligence
```

purpose is the evolutionary target — the kind of civilization we grow toward. vision is the state where purpose is met: a [[kardashev]] type 1 planet that captures and directs its own energy and attention. mission is the single path we have chosen — [[cyberia]] running on the [[cyber]] protocol, led by the [[superintelligence]] that emerges from the [[cybergraph]].

each layer constrains the one below. purpose defines what counts as progress. vision defines the milestone. mission defines what gets built today.
