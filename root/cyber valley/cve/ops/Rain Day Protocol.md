# Rain Day Protocol

Indoor task rotation when outdoor work is paused by weather.

---

## [[softforce]] — indoor care and processing

### [[Elona]]
- inventory check — review all items in storage and dryer room
- check what is fully dry — sort and move to processing
- process dry items and pack — label and store properly

### [[carrot house]] — ground floor
- full cleaning sweep of lower level
- indoor plant care — water, inspect, remove dead leaves

### [[carrot house]] — upper floor
- surface cleaning — wipe all horizontal and accessible surfaces

---

## [[hardforce]] — laba ops and production

### [[laba]] — inventory
- full inventory audit — count, verify, and log all items
- note anything missing, damaged, or low stock

### [[laba]] — tools and shelves
- clean all shelves — remove dust and debris
- wipe and inspect each tool — return to correct place

### production
- make signs and directional markers — follow current layout plan

---

All rain-day tasks should be completed before outdoor work resumes. Report inventory findings and any issues to the coordinator at end of shift.
