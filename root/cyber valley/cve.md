## relationship to agent network

CVE is the legal shell through which agent decisions become real-world actions:

| agent decision | CVE execution |
|---|---|
| "hire seasonal worker for harvest" | [[joy]] processes employment contract through CVE |
| "purchase 100 seedlings" | runner creates purchase order, CVE bank account pays supplier |
| "host 30-person retreat next month" | socio-runner plans, CVE issues invoices and receives payment |
| "repair water pump #3" | tech-runner assigns staff, CVE pays for parts |

agents plan and coordinate. CVE executes legally. the separation is structural: agents cannot sign contracts, open bank accounts, or employ people. CVE can. [[joy]] bridges between agents and CVE
