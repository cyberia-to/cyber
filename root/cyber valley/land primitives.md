- five primitives for all land operations
- ## Primitives
  | Element | Purpose | Surface |
  |---------|---------|---------|
  | [[plot]] | Construction | Flat, cleared |
  | [[pond]] | Water retention | Basin |
  | [[road]] | Vehicle access | Continuous grade |
  | [[terrace]] | Cultivation | Contoured slopes |
  | [[trail]] | Foot traffic | Any grade, stairs OK |
- ## Distinctions
	- [[plot]] vs [[terrace]] — both can be cut into slopes. Plot is for building, terrace is for growing.
	- [[road]] vs [[trail]] — road allows vehicles (no stairs). Trail allows stairs.
- ## Principles
	- Every clearing operation has a target type
	- Drainage is integrated into all elements
	- Protected forest is outside this grammar (separate management)
	- Infrastructure (biogas, tanks) lives under buildings on plots
- ## Coverage
	- This set is complete and minimal. Every intervention on the land falls into one of these five types.
