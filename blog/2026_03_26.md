τ is token, not conviction. conviction = derived from age of unspent cyberlink.

## dual programming model

two objects to program. this combination exists nowhere else:

```
token   (balance)  — what you HAVE
neuron  (prog)     — what you DO
```

semcons = physics (what CAN happen). progs = agency (what DOES happen). cyberlink = action (neuron spends tokens to create knowledge edge).

proofs compose mathematically. no reentrancy, no call stack, no gas estimation. every application = semcon (type script) + optional prog (autonomous agent). no contract. no account.
