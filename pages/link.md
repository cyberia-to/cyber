directed edge between two nodes

the generic mathematical primitive: a relationship from one node to another in a [[graph]]

a [[cyberlink]] is a link that entered the [[cybergraph]] — signed, weighted, timestamped, settled in [[consensus]]. a link becomes a [[cyberlink]] when it achieves [[finality]]

in [[cyb]], a link starts as a local intent: memoized in [[local state]] before broadcast. once committed to the [[cybergraph]], it is a [[cyberlink]]

| | link | [[cyberlink]] |
|---|---|---|
| scope | local, private | global, public |
| where | [[graph]], [[local state]] | [[cybergraph]] |
| status | intent | settled |

see [[cyberlink]] for the protocol primitive. see [[graph]] for the generic structure
