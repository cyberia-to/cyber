output of a system routed back as input

the foundation of [[cybernetics]]. without feedback, there is no self-correction, no adaptation, no [[intelligence]]

in [[cyber]]: the [[neuron]] observes [[cyberank]] (output), adjusts [[cyberlinks]] (input), which changes the [[cybergraph]], which changes [[cyberank]]. the loop closes. every [[step]] the [[tru]] recomputes, every [[step]] the [[neuron]] can respond

positive feedback amplifies: popular [[particles]] attract more [[focus]], accelerating [[convergence]]

negative feedback stabilizes: overlinked [[particles]] dilute [[focus]], preventing monopoly

the observation loop is a feedback loop: [[observation]] → [[learning]] → [[cyberlink]] → [[cybergraph]] → [[tri-kernel]] → [[cyberank]] → [[observation]]
