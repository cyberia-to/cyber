deriving [[intelligence]] from [[knowledge]] in the [[cybergraph]]

inference is the read/compute operation of the protocol. its counterpart is [[learning]] — the write operation

| process | who | input | output |
|---|---|---|---|
| [[learning]] | [[neurons]] | [[particles]] | [[knowledge]] ([[explicit knowledge]]) |
| inference | [[truth machine]] | [[knowledge]] | [[intelligence]] ([[implicit knowledge]]) |

the [[truth machine]] performs inference by running the [[tri-kernel]] ([[diffusion]], [[springs]], [[heat]]) on the graph of [[cyberlinks]]

the result is [[cyberank]]: a probability distribution over all [[particles]] that encodes the collective judgment of all [[neurons]]. plus [[karma]] per [[neuron]] and [[syntropy]] of the [[vimputer]]

inference produces structure that no single [[neuron]] created — paths, clusters, hierarchies emerge from local links

## the ML analogy

in machine learning, inference runs a trained model on new input. in [[cyber]], inference runs the [[tri-kernel]] on the [[cybergraph]]. the graph is the model — trained by [[neurons]] through [[learning]], queried by the [[truth machine]] through inference

| | machine learning | [[cyber]] |
|---|---|---|
| process | inference | inference |
| who | forward pass | [[truth machine]] |
| model | neural network weights | [[cybergraph]] |
| input | query | [[knowledge]] (graph state) |
| output | prediction | [[intelligence]] ([[cyberank]], [[karma]], [[syntropy]]) |
| frequency | on demand | every [[block]] |

the key difference: in ML, inference runs on a single model trained by one entity. in [[cyber]], inference runs on a shared graph trained by millions of [[neurons]] — and the result is verified in [[consensus]]
