a [[particle]] given a `~` [[name]] — addressable, retrievable, meaningful

a [[particle]] cannot enter the [[cybergraph]] without at least one [[cyberlink]]. the first link — a `~` [[name]] — turns a particle into a file. before naming, a particle is [[information]]: identified by [[hash]] but unreachable by human language. after naming, it becomes a file: a content-addressed object with a human-readable label

the chain: [[data]] → [[information]] → file → [[knowledge]] → [[intelligence]]

a file is the bridge between [[information]] and [[knowledge]]. [[information]] is a particle that exists. a file is a particle that can be found. [[knowledge]] is [[particles]] linked to each other by [[neurons]]

every file is a [[particle]]. every [[particle]] in the [[cybergraph]] is a file — the protocol requires at least one [[cyberlink]] for submission, and the first link is always a [[name]]

to compute a [[particle]] from [[data]]: [[cyb/oracle]], [[cy]], or any [[ipfs]] tool
