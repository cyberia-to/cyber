the interchain ecosystem where [[bostrom]] — the bootloader for [[cyber]] — launched and operates. Cosmos provides the consensus engine (Tendermint/CometBFT), the SDK for building sovereign blockchains, and the IBC protocol for cross-chain communication

[[bostrom]] is a Cosmos SDK chain. it uses Tendermint BFT for [[consensus]], inheriting instant [[finality]] and a delegated proof-of-stake [[validators]] model. the Cosmos architecture gives bostrom sovereignty — its own validator set, governance, and [[state]] — while maintaining interoperability with other Cosmos chains through IBC

IBC (Inter-Blockchain Communication) allows [[tokens]] and data to flow between Cosmos chains. [[neurons]] on [[bostrom]] can transfer assets to and from other IBC-connected networks, bridging the [[cybergraph]] to the broader interchain economy

the [[cyber]] protocol extends beyond Cosmos. as the protocol matures, [[nox]] replaces the Cosmos SDK runtime with a native execution environment built on [[stark]] proofs and the [[cyber/bbg]] state structure. the Cosmos heritage remains in the consensus and networking layers

see [[bostrom]] for the bootloader chain. see [[federation]] for the governance model
